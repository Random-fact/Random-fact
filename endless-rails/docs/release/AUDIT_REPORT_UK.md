# ENDLESS RAILS 2.0.0 — фінальний аудит, оптимізація й мультиплатформна збірка

Дата: 24.11.2026 · Гілка: `claude/endless-rails-global-audit-u11yd8`

## Як і де перевірялось (прочитайте спершу)
* **Середовище:** хмарний Linux-контейнер без відеокарти, без Android-пристрою, без емулятора (немає KVM) і без Windows.
  Гра перевірялась у headless Chromium (Playwright) з програмним WebGL (SwiftShader) — це дає кілька кадрів за секунду,
  тому вимірювання продуктивності відносні (скільки разів малюється кадр, скільки часу забирає JavaScript), а не FPS
  реального пристрою.
* **Android:** справжня Gradle-збірка (Gradle 8.14.3, AGP 8.13.0, SDK 36, play-services-ads 25.5.0, UMP 4.0.0),
  Android Lint, перевірка підписів, дозволів, ID реклами і вмісту APK. **Запуск на пристрої, показ реклами й форма
  згоди не перевірялися** — немає пристрою/емулятора.
* **Windows:** справжня збірка Electron + NSIS. Інсталятор встановлено під Wine (тихо і з інтерфейсом): файли, ярлики й
  деінсталятор створюються. **Сама гра у Windows-.exe під Wine не стартувала** (процес Chromium зависає — обмеження
  Wine 9.0 у контейнері), тому той самий код застосунку (main.js, preload.js, app/) перевірено з Linux-збіркою
  Electron. На справжньому Windows запуск не перевірявся.
* **Web:** автономний `ENDLESS_RAILS.html`, відкритий як файл (`file://`) у Chromium.
* Нічого нижче не описує тест, якого не було.

## Не перевірено (потрібні пристрої / люди)
* Android на реальних телефонах і планшетах (продуктивність, нагрів, батарея, звук, жести, вирізи екрана, різні версії 7–16).
* Реальний показ реклами AdMob, нарахування нагороди, форма згоди UMP у ЄЕЗ, форма налаштувань конфіденційності.
* Windows-.exe на справжньому Windows (запуск, GPU, звук, повний екран на кількох моніторах, SmartScreen).
* FPS на реальних відеокартах; звук на динаміках (перевірявся лише стан аудіосистеми).
* Носійна перевірка 9 перекладів (переклади зроблені машинно з глосарієм).

## Відомі обмеження й залишкові питання
* Windows-файли **не підписані** сертифікатом коду — SmartScreen попереджає при першому запуску.
* Ключ підпису Android має «робочий» пароль — змініть його або створіть новий ключ завантаження перед Google Play (`SIGNING.md`).
* Електронна гра під Wine 9.0 не стартує (обмеження Wine, не гри) — для перевірки потрібен справжній Windows.
* 13 попереджень Lint — косметичні (форма круглої іконки для Android 7.0–7.1, атрибути для новіших API, фіксована
  орієнтація ігнорується на великих екранах Android 16 — гра підтримує й портрет).
* Подія «Ремонт колії»: техніка стоїть на баласті другої колії — так задумано (колія закрита на ремонт), на рейках нічого немає.
* «Повалене дерево»: якщо поруч немає безпечного місця (схил, станція, переїзд), подія пропускається (≈40 % спроб у тісній місцевості).
* Склад назв станцій — з половинок слів (напр. «Холоднськ»): генератор не змінювався, змінено лише порядок без повторів.
* Web: звук починається після першого дотику/кліку (правило браузерів); у Web-версії й на Windows реклами немає — усі додатки безкоштовні.
