# ENDLESS RAILS → Google Play: пакет для нової сесії

## Що в пакеті
| Файл / папка | Для чого |
|---|---|
| `SESSION_PROMPT.md` | **Повідомлення для нової сесії Claude** — весь контекст, порядок дій і правила безпеки. Скопіюй його повністю як перше повідомлення. |
| `PLAY_CONSOLE_ANSWERS_UK.md` | Готова відповідь для кожної форми Play Console (вміст застосунку, рейтинг, Data safety, сторінка магазину, тестування, AdMob). |
| `TESTERS_INVITE_UK.md` | Текст запрошення для 12+ тестувальників (укр. + англ.). |
| `upload/ENDLESS_RAILS.aab` | Файл, який завантажується в Google Play. |
| `upload/ENDLESS_RAILS_debug.apk` | Версія лише з тестовою рекламою Google — щоб безпечно перевірити рекламу на своєму телефоні. |
| `store/` | Іконка 512×512, обкладинка 1024×500, свіжі скриншоти, тексти магазину 10 мовами (`listing/*.txt`). |
| `website/` | Сайт розробника для GitHub Pages: політика конфіденційності, `app-ads.txt`, головна сторінка + інструкція. |

**Ключа підпису тут немає навмисно.** Він в окремому архіві `ENDLESS_RAILS_SIGNING_KEY.zip`: тримай його в
безпеці й нікуди не завантажуй. Для Google Play він не потрібен, бо AAB уже підписаний.

## Як запустити нову сесію з керуванням браузером
1. Розпакуй цей архів у зручну папку на своєму комп'ютері, наприклад `Документи\ENDLESS_RAILS_PLAY`.
2. Відкрий застосунок **Claude** на комп'ютері й увімкни керування браузером (**Claude in Chrome** або **керування комп'ютером**), якщо ще не ввімкнено.
3. Почни нову розмову або сесію Claude Code в цій папці, щоб Claude бачив файли пакета.
4. Встав увесь текст із `SESSION_PROMPT.md` першим повідомленням.

## Що буде твоєю частиною (Claude цього не робитиме за тебе)
* Реєстрація в Play Console, оплата **$25**, перевірка особи й телефону, прийняття угод Google.
* Вхід у свої акаунти (Google, GitHub, AdMob): паролі вводиш сам.
* Знайти **12+ тестувальників** (email-адреси Google-акаунтів). Для нового особистого акаунта тест триває 14 днів.
* Сказати «так» перед кожною відправкою на перевірку чи публікацією.

## Що мати під рукою
* Google-акаунт для розробника, банківська картка, документ, що посвідчує особу, телефон.
* Ім'я або назва розробника, країна, публічний email для зв'язку.
* Акаунт GitHub (для безкоштовного сайту з політикою конфіденційності).
* Список email тестувальників.

## Скільки це займе
* Підготовка, сайт і заповнення форм: 1–2 години.
* Перевірка акаунта: кілька днів.
* Закрите тестування: 14 днів.
* Розгляд доступу до продакшну: до ~7 днів.
* Розгляд релізу: від кількох годин до кількох днів.
