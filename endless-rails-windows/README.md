# Endless Rails для Windows

Гра `game/index.html`, запакована в окрему програму для Windows 10/11 (`EndlessRails.exe`).

## Як запустити

1. Скопіюйте `EndlessRails.exe` в будь-яку папку (наприклад, на робочий стіл) і запустіть.
2. Windows може показати синє вікно «Windows захистила ваш ПК» (SmartScreen), бо програма не має платного цифрового підпису.
   Натисніть **«Докладніше» → «Усе одно запустити»**. Це потрібно зробити лише один раз.

Інтернет не потрібен: гра, музика й шрифти вбудовані у файл.

## Керування вікном

| Клавіша | Дія |
|---|---|
| **F11** або **Alt+Enter** | повноекранний режим / вікно (режим запам'ятовується) |
| **Alt+F4** або хрестик | вийти (поїздка й профіль зберігаються перед закриттям) |

## Де зберігаються дані

`%LOCALAPPDATA%\EndlessRails`: збереження гри, налаштування вікна та `log.txt` для діагностики.
Щоб почати з нуля, видаліть цю папку.

## Вимоги

Microsoft Edge WebView2 Runtime. У Windows 11 він вже встановлений, а у Windows 10 приходить з оновленнями.
Якщо його немає, програма сама запропонує відкрити сторінку завантаження.

## Як зібрати самостійно

Потрібен Go 1.24+. Збирати можна з Linux, macOS або Windows:

```sh
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-H windowsgui -s -w" -o dist/EndlessRails.exe .
```

Якщо ви змінили гру, замініть `game/index.html` і зберіть заново.
Якщо змінили іконку (`winres/icon.png`) або дані версії (`winres/winres.json`), спочатку виконайте
`go run github.com/tc-hib/go-winres@latest make --arch amd64`.

GitHub Actions (`.github/workflows/endless-rails-windows.yml`) збирає `.exe` на Windows при кожній зміні
в цій папці. Потім запускає програму, проходить меню, починає поїздку й перевіряє, що збереження лишилося після перезапуску.
Готовий файл лежить в артефакті `EndlessRails-Windows`.

`--debug` у командному рядку вмикає інструменти розробника (F12) і контекстне меню.
